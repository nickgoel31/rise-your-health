# Rise Your Health — The PCOS Reset Method

A premium, high-performance web platform built for **Rise Your Health** and **The PCOS Reset Method** — 16 Weeks to Better Hormonal & Metabolic Health.

## Tech Stack
- **Framework**: Next.js 16+ (App Router, Turbopack)
- **Styling**: Tailwind CSS v4
- **Smooth Scroll**: Lenis
- **Fonts**: Instrument Serif & Instrument Sans (Google Fonts)
- **Language**: TypeScript

## Key Features
- **Cinematic Hero**: Video background with responsive navigation and dynamic CTA triggers.
- **Interactive 3D Orbit & Mobile Snap Carousel**: Visualizing common hormonal & metabolic patterns.
- **The 5 Pillars**: Continuous clinical assessment, nutrition, movement, stress/cortisol, and accountability.
- **Interactive 16-Week Roadmap**: Accordion milestones and Objective Health Scorecard.
- **Client Stories**: Localized Indian client transformations with flat, minimal card layout.
- **Full Interactive Intake Assessment Modal**: 4-step personalized discovery flow with Lenis scroll lock.
- **Legal Compliance**: Privacy Policy, Terms of Service, and Refund Policy pages.

## Getting Started

```bash
# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production
npm run build
```
